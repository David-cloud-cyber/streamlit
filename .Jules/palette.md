## 2025-07-31 - Sidebar Navigation and Decorative Icons Accessibility Pattern
**Learning:** For interactive navigation, assigning `aria-current="page"` to active links/buttons provides key context to assistive technologies. Additionally, embedding SVG or icon packs like Lucide React inside buttons can lead to redundant audio announcements if they aren't explicitly hidden using `aria-hidden="true"`. Wrapping label text and required indicator markers inside nested flex containers prevents layout issues in screens using `justify-content: space-between`.
**Action:** Always wrap labels and indicators in a separate nested flexbox when using `space-between` styles, apply `aria-hidden="true"` to SVG/decorative containers, and leverage `aria-current` to improve keyboard navigation feedback.
