# Palette's Journal - MoneyPrinterTurbo Studio UX learnings

This file contains critical, unique UX and accessibility learnings from working with this codebase.

## 2025-01-24 - Initial Review
**Learning:** The App is a single page application built in React/Vite with Tailwind CSS. The interface is in French, serving as a SaaS video generator interface.
**Action:** Always maintain consistency with French wording, existing accentuation, and class-based layouts. Ensure keyboard and screen reader accessibility are first-class citizens.
