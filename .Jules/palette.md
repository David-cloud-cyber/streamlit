## 2025-08-11 - Field label alignment with required asterisks
**Learning:** In design systems where fields/label containers use flex properties like `justify-content: space-between` or general block styles, rendering a required asterisk directly as a sibling inside the container can cause them to be visual islands separated from the text. Wrapping both the label text and the required asterisk in a nested flex container (e.g. `span className="flex items-center gap-1"`) keeps them closely grouped regardless of the parent layout style.
**Action:** When adding required asterisks next to form labels in components utilizing `field-label` styles, always wrap the label text and asterisk in a nested flex helper or local inline-flex container to guarantee proximity and readability.
