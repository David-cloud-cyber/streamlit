## 2025-02-12 - Required Asterisks, Sidebar, & Toast Accessibility Improvements
**Learning:** Wrapping label text and required asterisks in a nested flex container (e.g., `span className="flex items-center gap-1"`) ensures they stay visually close together regardless of outer element's layout and alignment properties. Adding `aria-current="page"` to the active navigation element and `aria-hidden="true"` to icons and section titles reduces screen reader noise while improving context. Dynamic alerts (like toasts) must contain `role="alert"` for prompt screen-reader announcement.
**Action:** Always wrap label elements needing indicators with a nested flex container to keep contents aligned, mark active sidebar nav components with standard ARIA roles/states, hide purely decorative icons with `aria-hidden`, and ensure toast/notification alerts use role="alert".
