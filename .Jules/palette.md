## 2025-05-15 - Visual indicator for required fields
**Learning:** Adding a visual indicator (like a red asterisk) to labels for required fields improves UX by making mandatory inputs immediately obvious. It should be paired with the semantic `required` attribute on the input itself and `aria-hidden="true"` on the visual-only asterisk for better accessibility.
**Action:** Always ensure that visual required indicators are consistent with underlying form validation attributes.
