## 2025-02-21 - Aligning Asterisks with Label Flex Containers
**Learning:** When using flexbox headers with properties like `justify-content: space-between` (as in `.field-label`), adding a visual required asterisk can cause the asterisk to float far away from the label text. To prevent this, wrap both the label text and the asterisk in a nested container with `display: flex` and a small gap (e.g., `flex items-center gap-1`). Additionally, ensure the visual indicator has `aria-hidden="true"` so screen readers are not burdened with hearing "star" or "asterisk", while the input element itself possesses the functional `required` attribute.
**Action:** Always nest label elements and visual required marks in tight flex containers inside larger aligned labels, and pair with appropriate ARIA hidden tags.
